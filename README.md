# Ateliê Neia Biscuit — Loja virtual (React + Vite)
Rodar: `npm install` e `npm run dev`. Publicar: `npm run build`.
Tudo editável em `src/data/products.js`: links (Shopee, TikTok, Instagram, WhatsApp), categorias, os 30 produtos, FAQ e texto "Sobre".
Fotos: coloque em `public/produtos/` (ex.: 01.jpg) e preencha `image: "/produtos/01.jpg"` no produto.
Foto do hero: salve em `public/hero.jpg` e troque o bloco `.hero-ph` em `src/App.jsx` por `<img src="/hero.jpg" alt="..." />`.
Os preços atuais são EXEMPLOS e devem ser substituídos. O checkout está preparado em `Cart` (App.jsx), sem pagamento simulado.
